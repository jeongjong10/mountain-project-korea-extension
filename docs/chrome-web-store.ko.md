# Chrome 웹 스토어 제출 문안

최초 작성: 2026-09-28. 현재 상태 갱신: 2026-09-29. 첫 배포 버전 `0.1.0`은 사용자가 심사 제출을 완료했으며 검토 대기·승인 후 자동 게시 상태입니다. 아래 문안은 제출·후속 수정 시 참고하는 키트이며 실제 제출 필드의 사본은 아닙니다. 최신 상태는 [출시 현황](release-status.md)을 따릅니다. 날짜별 공개·검증 이력은 당시 기록으로 보존합니다.

## 1. 이름과 짧은 설명

이름 (`manifest.name`):

```text
Mountain Project Korea (비공식)
```

짧은 설명 (`manifest.description`):

```text
Mountain Project 지원 페이지의 한국어 번역과 탐색을 돕는 비공식 확장 프로그램.
```

두 문구는 [wxt.config.ts](../wxt.config.ts)와 동일합니다. 공식 manifest 제한은 이름 75자, 설명 132자이며 공백도 포함합니다. 업로드된 패키지의 manifest 메타데이터는 스토어 입력란만 수정해서 바꿀 수 없습니다. [이름 규격](https://developer.chrome.com/docs/extensions/reference/manifest/name), [설명 규격](https://developer.chrome.com/docs/extensions/reference/manifest/description), [제출 준비](https://developer.chrome.com/docs/webstore/prepare)

비공식 표시는 공식 제작·승인·제휴로 오인하지 않도록 하기 위한 것입니다. 상표나 사이트 콘텐츠의 이용 허가를 취득했다는 뜻은 아닙니다. [스토어 사칭·오인 관련 안내](https://developer.chrome.com/docs/webstore/troubleshooting#deceptive_behavior)

## 2. 상세 설명

```text
Mountain Project Korea (비공식)는 Mountain Project의 지원 페이지를 한국어로 읽고 탐색하도록 돕는 확장 프로그램입니다. Mountain Project 및 onX의 공식 제품이 아니며 두 서비스와 제휴하지 않습니다.

주요 기능
- 내비게이션, 버튼, 검색·폼 안내와 클라이밍 용어 등 지원되는 고정 문구를 한국어로 표시합니다.
- 지역에 관계없이 지원되는 Area, Route, Route Finder, Photo 페이지의 본문·설명·댓글을 영어에서 한국어로 번역합니다. 루트 통계의 등반 기록 메모, 짐·새 소식의 댓글, 포럼 토픽과 도움말의 지원 영역도 번역합니다.
- 원문·번역을 분리해 표시하는 본문, 댓글과 등반 기록에서는 원문을 확인하거나 해당 섹션을 다시 번역할 수 있습니다. 재번역 중에는 기존 결과를 유지하고, 실패하면 원문과 기존 결과를 잃지 않습니다. 짧은 제목처럼 화면에서 직접 치환하는 일부 문구에는 이 컨트롤이 표시되지 않습니다.
- 현재 지역 지도와 루트 통계를 페이지 안에 표시하고, 지원되는 섹션·목록·사이드바의 표시를 개선합니다.
- 대한민국 지역 바로가기와 한국 지역 목록·Classic Routes 정리를 제공합니다.
- 페이지 상단과 확장 팝업에서 기능을 켜고 끌 수 있습니다. 기본값은 ON이며 설정은 같은 브라우저 프로필에 저장됩니다. OFF로 바꾸면 페이지 기능을 중단·복원하고, 다시 켤 수 있는 상단 컨트롤 바와 대한민국 링크는 남습니다.

지원 범위와 번역 조건
데스크톱 Chrome을 대상으로 합니다. 고정 UI는 확장에 포함된 사전과 규칙을 사용하며, 본문 자동 번역은 Chrome 내장 Translator API와 영어·한국어 언어팩이 준비된 환경에서 동작합니다. 최초 모델·언어팩 다운로드에는 네트워크 연결과 브라우저가 요구하는 사용자 상호작용이 필요할 수 있습니다. 준비가 필요하면 기다렸다가 페이지 상호작용 후 재시도합니다. 번역을 사용할 수 없거나 실패하면 원문을 유지하며 외부 번역 서비스로 자동 전환하지 않습니다.

사이트 전체의 모든 문장·이미지·페이지를 번역하는 제품은 아닙니다. 사용자 프로필·기여·연락 페이지는 고정 UI를 중심으로 처리합니다. Help Hub의 Feature Request 제목·설명은 지원 영역에서 자동 번역하고 원문 보기·재번역을 제공하며, 작성자·투표 수·폼 입력값은 보존합니다. 사이트 구조가 바뀌거나 필요한 화면 요소를 찾지 못하면 해당 기능을 건너뛸 수 있습니다. 모바일과 Firefox·Safari 등 다른 브라우저에서 동일한 기능을 보장하지 않습니다. 기계 번역은 오류가 있을 수 있고 재번역 결과가 같을 수도 있으므로 필요한 내용은 원문과 대조할 수 있습니다.

권한과 데이터 처리
storage 권한은 ON/OFF 설정을 기기에 저장하는 데 사용합니다. 사이트 접근은 https://mountainproject.com/* 와 https://www.mountainproject.com/* 에 한정됩니다. 현재 페이지와 일치하는 프레임의 주소·화면 구조·지원 텍스트를 읽어 현지화와 탐색 기능에 사용합니다. 표시된 사용자명이나 게시물에 개인정보가 포함될 수 있습니다.

원문·번역 결과·복원 기록과 번역 캐시는 페이지·프레임 메모리에 임시 보관하며, 본문 번역은 기기 내에서 처리합니다. 지속 저장하는 확장 설정은 enabled 값입니다. 개발자 서버로 본문이나 사용 기록을 보내는 기능, 원격 분석 또는 자체 광고 추적 기능은 없습니다.

지도는 처음 펼칠 때, 루트 통계는 지원 페이지에서 기능이 ON이면 별도 클릭 없이 Mountain Project의 웹페이지를 iframe으로 불러올 수 있습니다. 실제 로딩 시점은 브라우저의 지연 로딩 처리에 따라 달라집니다. 원본 사이트와 그 페이지의 리소스 제공자에게 추가 요청이 발생하며, IP 주소·일반 요청 정보 및 브라우저 설정에 따른 사이트 쿠키가 사용될 수 있습니다. 지도를 접는 것만으로 통신이 종료되지는 않으며, OFF로 바꾸면 추가한 지도·통계 화면을 제거합니다. 지역 디렉터리 등록 수는 불러오기 버튼을 누를 때 공개 지역 페이지를 직접 조회하며 이 HTML 요청에는 쿠키를 보내지 않습니다.

문의 이메일로 직접 보내는 주소·본문·첨부자료는 개발자가 답변과 문제 확인을 위해 받습니다. 답변과 후속 확인을 마치면 불필요한 기록·첨부파일을 지체 없이 삭제합니다. 자세한 중단·삭제·권리 요청 방법은 이 스토어 항목에 연결된 개인정보처리방침을 확인해 주세요.
```

스토어 기본 언어는 한국어로 설정합니다. 제목·짧은 설명과 별도로 상세 설명 입력란에 위 본문을 사용합니다. 마지막 문장의 방침 링크는 아래 게시 상태를 확인하고 실제 공개 URL을 스토어에 연결한 뒤 유효해집니다. [스토어 정보 입력 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)

## 3. 단일 목적과 권한 사유

Single purpose description:

```text
Mountain Project의 지원 페이지를 한국어로 읽고 탐색하도록 돕습니다. 고정 UI 현지화, 지원 본문·댓글의 기기 내 영어-한국어 번역, 원문 확인, 지역 지도·루트 통계 표시와 대한민국 지역 탐색은 모두 이 목적을 위한 기능입니다.
```

`storage` justification:

```text
확장 기능의 ON/OFF 값(enabled)을 storage.local에 저장하고, 같은 브라우저 프로필의 페이지와 팝업에 설정 변경을 반영합니다. 본문·번역 결과나 방문 이력을 이 저장소에 저장하지 않으며 storage.sync를 사용하지 않습니다.
```

Host permission justification (두 호스트 입력란에 공통 사용):

```text
https://mountainproject.com/* 및 https://www.mountainproject.com/* 의 지원 페이지와 일치하는 프레임에서 주소·DOM·텍스트를 읽어 한국어 현지화, 본문 번역·원문 복원, 지도·통계 표시와 탐색 UI를 제공합니다. www 유무에 따른 두 사이트 주소를 지원합니다. 여러 지역과 페이지 유형에서 기본 ON 상태로 동작하므로 한 경로나 일회성 탭 접근으로 제한할 수 없습니다. 다른 사이트 전체에 대한 접근은 요청하지 않습니다.
```

현재 요청 권한은 위 세 항목입니다. `allFrames: true`는 일치하는 프레임에도 적용한다는 설정이며 별도 권한이 아닙니다. `history`·`cookies` API 권한은 없지만 현재 페이지 URL을 읽고 일반 iframe 요청에 사이트 쿠키가 동반될 수 있다는 사실은 공개합니다. [개인정보 필드·최소 권한 사유 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 4. 원격 코드 (MV3)

대시보드가 확장 외부에서 실행되는 코드 전반을 묻는 경우의 보수적 기재안: **Yes**, 아래 사유로 원격 사이트 iframe 사용을 공개합니다. 이를 확장 실행 맥락에서 원격 JS를 내려받아 실행한다는 의미로 기재하지 않습니다. 실제 양식이 해당 맥락만을 한정해 묻는다면 답은 **No**이고, iframe 설명은 심사 메모에 함께 제공합니다. 최초 작성 시에는 실제 양식을 확인하지 않았습니다. 2026-09-29 사용자가 전달한 양식은 패키지에 포함되지 않은 모든 JS/Wasm을 원격 코드로 설명하므로, iframe 동작을 공개하는 Yes와 아래 근거를 안내했습니다. 사용자가 입력·제출 완료를 알렸으나 실제 저장된 각 필드 값의 사본을 확인한 것은 아닙니다.

Remote code justification / 심사 메모:

```text
확장 프로그램의 실행 로직과 고정 번역 사전은 패키지에 포함됩니다. 확장 실행 맥락으로 원격 JavaScript/WASM을 다운로드하거나, 내려받은 문자열을 eval로 실행하거나, 원격 명령으로 기능을 구성하지 않습니다. 본문 번역은 브라우저 내장 Translator API를 호출하며 모델 다운로드는 Chrome이 관리합니다.

다만 콘텐츠 스크립트가 Mountain Project의 지도와 루트 통계 웹페이지를 일반 웹 iframe으로 표시합니다. 이 문서는 원본 사이트의 스크립트와 리소스를 로드할 수 있습니다. 사이트 스크립트가 실행되는 웹페이지 맥락과 패키지의 콘텐츠 스크립트 실행 맥락은 구분되며, 원격 사이트 코드를 확장 API로 실행하는 브리지를 제공하지 않습니다. 패키지 콘텐츠 스크립트는 허용 호스트와 일치하는 프레임에서도 현지화를 수행합니다. iframe 요청에 따른 데이터 처리는 개인정보처리방침에 공개합니다.
```

MV3 정책은 확장 API와 격리된 iframe 등의 맥락을 별도로 다루지만, 기능을 제출 코드에서 파악할 수 있어야 하고 사용자 데이터 정책도 적용됩니다. 위 판단은 현재 소스에 근거합니다. 최종 제출 ZIP의 번들·의존성 검사는 별도 빌드 검증 결과와 대조해야 하며, 이 문서는 스토어의 면제·승인을 확정하지 않습니다. [MV3 추가 요구사항](https://developer.chrome.com/docs/webstore/program-policies/mv3-requirements), [원격 코드 검사 안내](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code)

아래는 대체 호스팅 완료 전 기록이다. 미게시·게시 경로 관련 현재 상태는 위 공개 완료 기록으로 대체한다.

2026-09-28 게시 시도 결과: 저장소는 공개 상태이며 GitHub Pages는 비활성입니다. 연결된 GitHub 도구의 Pages API 조회는 지원 대상 밖으로 거부되었고, 게시 전용 트리 생성은 `403 Resource not accessible by integration`으로 거부되었습니다. 사용 가능한 로컬 GitHub 인증도 없었습니다. 원격 파일·브랜치·커밋은 생성하지 않았습니다. 게시하려면 이 실행 환경에 저장소 파일 쓰기와 Pages 생성 권한이 있는 GitHub 인증을 연결해야 합니다. 이후 `privacy-site/index.html`과 `privacy-site/.nojekyll`만 별도 게시 브랜치에 올리고 Pages를 활성화합니다. 실제 제출 시에는 배포 ZIP과 공개 방침의 일치, 대시보드의 최신 범주 정의를 확인합니다. 이름 변경에 따른 버전 올리기, 권한 변경, 설치, 패키지 빌드, 스토어 제출, 공개 호스팅, 외부 연락은 이 문서 작성 작업에서 수행하지 않았습니다. 아이콘·스크린샷 제작은 이 문안 키트의 범위 밖이며 전체 제출 자산이 갖춰졌다는 뜻은 아닙니다.
