# 해외 원정지 공동 선정 조사

조사일: 2026-09-28. **선정 과정의 근거 기록이다. 후속 사용자 요청으로 해외 15개국·65개 지역이 구현에 반영되었다. 현재 기능 명세는 [지역 디렉터리](region-directory.md)를 따른다. 이 문서의 수치는 조사 당시 기록이며 화면에 배포하는 고정 수치가 아니다.**

## 조사 범위 확장: MP 기존 등록 목록을 모집단으로 사용

기존 12~16개 후보만 비교했던 범위를 수정했다. [MP 전체 국가·지역 조사표](region-directory-mp-inventory.md)에 아시아 38개·유럽 45개 항목과 직속 하위 727개 항목을 수록하고, 주요 행정구역 아래 원정지를 추가 확인했다. [구조화 원자료](region-directory-mp-inventory.json)도 함께 보존한다.

선정 단위는 **나라 → 지역 n개**다. 국가별 개수를 미리 동일하게 제한하지 않는다. MP 기존 등록 목록에서 지역을 찾고, 각 지역에 한국인 실제 방문 근거·등반 유형·MP 자료량을 붙여 함께 선정한다. 아래의 기존 후보별 조사는 이 모집단 일부에 대한 근거이며 최종 후보 전체가 아니다. 뒤의 검색 캐시 수치보다 새 조사표의 직접 조회 값을 우선한다.

## 판단 기준 제안

1. 한국인의 실제 자연암벽 방문 기록을 우선한다. 방문 예정·희망과 구분한다.
2. 서로 다른 사람·팀과 시기의 반복 방문을 찾는다. 같은 원정의 기사·영상·인터뷰는 한 사례로 취급한다.
3. 선수의 고난도 프로젝트, 일반 동호인 여행, 대학산악부 원정을 구분한다.
4. 사용자와 등반 유형·지역별 비중을 합의한 다음 바로가기 개수와 MP 정보의 활용도를 검토한다. 기존 6+6은 고정 조건이 아니다.

공개 검색에서 확인한 사례는 방문 빈도 통계가 아니다. 검색 노출이 적다는 이유로 방문자가 적다고 판단하지 않는다. 한국어로 번역된 외국인 후기·상품 소개는 한국인 방문 증거에서 제외한다. 아르코 대회 출전 역시 자연암벽 방문과 구분한다.

## 자료 접근 범위

Climbing Library 이민영 인터뷰와 Polar Safety 소개는 본문을 열어 확인했다. 일부 월간산·루트파인더스·Better Weekend 등은 직접 열기가 403 또는 캐시 오류로 실패해 검색 도구에 제공된 기사 발췌를 근거로 기록했다. 글 전체를 검토했다고 주장하지 않는다. 게시물 수·검색 결과 수를 인기 점수로 사용하지 않았다.

## 조사 당시 논의 항목

- 스포츠클라이밍 / 볼더링 / 트래드·멀티피치의 비중.
- 전체 MP 등록 목록에서 국가별로 어떤 지역을 남길지. 신규 발견 지역의 국내 방문 근거를 어디까지 보완할지.
- 일반 동호인의 휴가 원정과 선수 프로젝트 중 어느 이용층에 더 맞출지.
- 목적지를 정한 뒤 아시아·유럽 바로가기 수와 순서 결정.

### 범위·등반 유형 보정

- 기존 깟바 링크의 [Butterfly Valley](https://www.mountainproject.com/area/107070263/butterfly-valley)는 70개다. 깟바 섬 145개에 포함되므로 합산하지 않는다. 상위 [Ha Long Bay](https://www.mountainproject.com/area/107070390/ha-long-bay)는 218개이며 깟바 섬과 Lan Ha Bay를 포함한다. 사용자와 섬 또는 만 전체 중 바로가기 범위를 정해야 한다.
- [대만 상위 목록](https://www.mountainproject.com/area/106444540/taiwan)에서 롱동은 Trad 169, Sport 96, Toprope 11, Boulder 1로 표시된다. 유형은 중복 지정될 수 있으므로 합계가 Total Climbs와 같지 않다. 스포츠 중심이면 전체 268보다 Sport 96을 별도로 보는 것이 맞다.
- [베트남 상위 목록](https://www.mountainproject.com/area/107058176/vietnam)에서 후룽은 총 174 중 Sport 170. 깟바 섬은 [Ha Long Bay 목록](https://www.mountainproject.com/area/107070390/ha-long-bay)에서 총 145 중 Sport 137. 퐁텐블로·미타케는 볼더링 지역이므로 스포츠 루트 수와 같은 종목의 자료처럼 비교하지 않는다.
- 사진·설명·댓글의 충실도와 최근 갱신 여부는 아직 전수 조사하지 않았다. 등록 수만으로 자료 품질까지 입증했다고 간주하지 않는다.

### 조사 당시 선정 제안과 후속 반영

전체 MP 국가·지역 목록을 출발점으로 사용한다. 기존 후보는 유지해 비교하되 후보군의 한계로 삼지 않는다. 한국인 방문 근거와 MP 자료 활용도 두 축을 유지하고 임의 가중치로 인기 점수를 만들지 않는다. 국가별 지역 수 n은 사용자와 선택한 결과로 정한다.

새 조사에서 기존 목록 밖의 프랑켄주라, 레오니디오, 엘초로, 출리야, 피날레 리구레, 게이이크바이르, 중국 윈난 하위 지역, 태국 크레이지 호스 등을 확인했다. MP 등록만으로 한국인 선호 지역이라고 주장하지 않는다. 전수 목록의 행정구역·개별 암장을 동일한 범위처럼 단순 순위화하지 않는다.

후속 사용자 요청에 따라 비교 초안의 15개국·65개 지역을 아시아·유럽 전환 탭에 국가별로 반영했다. 전체 조사 모집단 83개 항목을 모두 화면에 넣은 것은 아니다. 아메리카 탭에서는 원본 전체 목록을 유지한다. 등록 수는 사용자가 요청할 때만 MP에서 조회한다. 구현 명세는 [지역 디렉터리](region-directory.md)를 따른다.
