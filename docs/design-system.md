# 화면 구성과 디자인

Mountain Project의 본문·링크·입력 흐름을 유지하면서 확장 조작부와 탐색 기능을 추가합니다. 색상·글꼴·간격의 공통 값은 [design-tokens.ts](../src/ui/design-tokens.ts)에서 관리합니다.

## 공통 스타일

| 요소 | 기준 |
| --- | --- |
| 상단 바·팝업 | 어두운 중성 배경, 흰 글자, 밝은 파란색 조작부 |
| 본문 조작·링크·포커스 | 파란색 `#0060a9` |
| 기본 본문·보조 문구 | `#202124`, `#59635d` |
| 기본·보조 표면 | `#fff`, `#f7f8f8` |
| 테두리 | `#c8ceca` |
| 글꼴 | 조작부는 시스템 글꼴, 원본 콘텐츠는 사이트 스타일 상속 |
| 간격 | `0.25 / 0.5 / 0.75 / 1 / 1.5rem` |
| 모서리 | 작은 요소 2px, 일반 조작부 4px, 상단 바 7px |

`UI.nav`의 표면은 `#202124`, 글자는 `#fff`, 링크·포커스는 `#91c3e8`, ON 스위치는 `#5ba2d8`, OFF·테두리는 `#5f6368`입니다. 일반 상태 전환은 `150ms ease`를 사용합니다. 각 구성요소가 토큰을 참조하며 팝업은 `--mpkr-*` CSS 변수를 사용합니다. 사이드바 폭·프레임 높이·탭 간격은 담당 구성요소에서 관리하고, Classic Routes 그룹과 태극 SVG의 의미별 색상은 유지합니다.

원문 보기·재번역은 밑줄 텍스트 조작부를 사용합니다. hover, 키보드 포커스와 진행 상태를 구분하며 색상만으로 ON/OFF를 전달하지 않습니다. 확장 아이콘은 [public/icon/](../public/icon/)에 두고 [WXT 설정](../wxt.config.ts)에서 연결합니다.

대표 아이콘은 Mountain Project 클라이머 심벌에 `KOREA` 표기를 결합한 이미지입니다. 패키지 크기는 16·32·48·128px이며 툴바에는 16·32px를 사용합니다. 제3자 고지는 [THIRD_PARTY_NOTICES.txt](../public/THIRD_PARTY_NOTICES.txt)에 둡니다.

## 상단 컨트롤과 팝업

상단 사용자 메뉴 앞에 **확장 기능 → 대한민국 → 원본 사용자 메뉴** 순서로 배치합니다. 비로그인 상태에서는 Sign In 앞에 표시합니다. 원본 아바타·링크·드롭다운의 클릭 영역을 유지하고, 지원 헤더가 없으면 삽입을 건너뜁니다.

`확장 기능`은 번역, 지도·통계와 페이지 편의 기능을 함께 제어합니다. native checkbox의 switch 역할을 사용하며 Tab·Space로 조작합니다. OFF에서도 다시 켤 수 있도록 상단 바와 대한민국 링크는 남습니다.

팝업은 같은 설정을 사용하고 스위치 옆에 켜짐·꺼짐을 표시합니다. 대한민국 지역, 사용 안내와 문의 링크를 제공하며 설정 조회·저장 실패를 알립니다. 설정 저장과 종료 처리는 [프로젝트 구조](architecture.md#시작과-설정)를 따릅니다.

관련 코드: [navigation-controls.ts](../src/ui/navigation-controls.ts), [navigation-control-style.ts](../src/ui/navigation-control-style.ts), [popup/](../src/entrypoints/popup/).

## 첫 실행 안내

설정 키가 없으면 OFF로 시작하며 상단 스위치를 강조하고 주변을 어둡게 표시합니다. 안내 문구는 `스위치를 켜서 한국어 기능을 시작하세요`입니다.

배경 암전은 페이지 클릭을 막지 않습니다. 스크롤·리사이즈에 맞춰 위치를 갱신하고 안내를 화면 안에 배치합니다. `prefers-reduced-motion`에서는 강조 애니메이션을 끕니다.

ON 저장이 반영되면 안내를 제거합니다. 저장 실패 시 암전을 숨기고 설정 오류와 재시도 방법을 표시합니다. 키가 계속 없으면 다음 페이지에서도 첫 실행 상태로 처리합니다. 번역 모델 준비 상태는 [번역 안내](translation-runtime.md#엔진-준비와-상태-안내)에서 별도로 관리합니다.

관련 코드: [first-run-onboarding.ts](../src/ui/first-run-onboarding.ts).

## 지역 디렉터리

`#route-guide`가 있는 페이지에서 아시아·유럽·아메리카 탭을 제공합니다. 첫 선택은 아시아이며 대한민국 6개 권역을 먼저 표시합니다. 아시아에는 해외 8개국·34개 지역, 유럽에는 7개국·31개 지역을 구성합니다. 국가명과 지역명은 각각 해당 MP 페이지로 이동합니다. 아메리카 탭은 International을 포함한 원본 디렉터리 전체를 표시합니다.

원본 목록의 글꼴·점선·들여쓰기를 활용하며 기본 4열, 991px 이하 2열, 543px 이하 1열로 배치합니다. 탭은 클릭, 좌우 방향키, Home·End로 전환하고 ARIA로 선택 상태와 패널을 연결합니다.

아시아·유럽의 등록 수는 `등록 수 불러오기` 버튼을 눌렀을 때만 조회합니다. 초기 로딩과 탭 전환에는 조회하지 않습니다. 아메리카는 원본 숫자를 사용하며 조회 버튼을 숨깁니다. 국가 수치는 국가 전체, 지역 수치는 하위 구역을 포함한 등록 루트·볼더 문제 수입니다.

- 같은 상위 페이지 요청은 중복 제거하며 동시에 2개까지 처리합니다. 제한 시간은 10초입니다.
- 현재 MP origin의 공개 HTML을 쿠키 없이 요청하고, HTML을 실행하지 않은 채 총수를 파싱합니다.
- 실제 0은 0으로 표시하고 실패·미인식 값은 빈칸으로 둡니다. 재시도 시 성공한 항목은 유지합니다.
- 조회 값과 시각은 구성요소의 메모리에 보관하며 새로고침 또는 OFF/ON 후에는 다시 버튼을 눌러야 합니다. OFF·종료 시 요청과 상태를 정리하고 원본의 표시 상태를 복원합니다.
- 원본 노드의 부모·순서를 유지하고 hidden 상태만 바꿉니다. 원본 디렉터리 자체를 동적으로 교체하는 화면은 별도 대응이 필요합니다. 로컬 `file:` 미리보기에서는 요청하지 않습니다.

관련 코드: [region-directory.ts](../src/ui/region-directory.ts), [directory-destinations.ts](../src/sites/mountain-project/contract/directory-destinations.ts), [directory-counts.ts](../src/sites/mountain-project/dom/directory-counts.ts).

## 지도·통계와 목록

Area 지도는 현재 지역을 표시하며 처음 펼칠 때 iframe을 생성합니다. 다시 접어도 iframe은 유지합니다. Route 통계는 지원 페이지에서 기능이 켜지면 iframe을 추가할 수 있습니다. OFF 시 추가한 프레임을 제거합니다.

루트 통계는 원본의 현재 로드된 기록과 `Show More`를 사용합니다. 등반 기록은 점진적으로 표시하고 화면에 가까운 메모부터 번역합니다. 고정 폭 차트는 원본 노드를 유지한 채 바깥 스크롤 영역으로 좁은 화면에 대응합니다.

지역·루트 섹션과 지원되는 왼쪽 사이드바는 접기·펼치기를 제공합니다. 목록의 링크 영역과 키보드 포커스를 구분하고, OFF 시 추가한 UI·스타일을 제거합니다.

관련 코드: [area-map-embed.ts](../src/ui/area-map-embed.ts), [route-stats-embed/](../src/ui/route-stats-embed/), [화면 테스트](../test/ui/).
