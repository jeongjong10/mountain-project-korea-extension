# 공통 디자인 기준과 단계별 컨펌

기준일: 2026-09-28. 이번 사용자 지시와 후속 수정 사항을 우선한다.

- 대표 아이콘은 MP 원본 클라이머 심벌에 `KOREA`를 추가한다. 후속 요청에 따라 글자가 하단 가로 폭 대부분을 차지하도록 확대했다.
- 현재 소스의 디자인 값을 추출해 공통화한다.
- **상단 바의 차콜·민트는 사용자가 원하는 디자인이 아니다.** 과거 문서의 ‘최종 선택’ 기록은 현재 선호의 근거로 사용하지 않는다.
- 밝은 회색·파란색 시안에서 후속 요청한 **다크 반전 시안이 승인됐다.** 어두운 중성 바탕·흰 글자·밝은 파란색 조작부를 실제 상단 바에 적용했다.
- 이후 팝업, 번역 상태 안내 등의 작업은 한 항목씩 결과를 보여주고 컨펌을 받은 뒤 이어간다.

단일 관리 파일: [design-tokens.ts](../src/ui/design-tokens.ts).

| 일반 상태 전환 | `150ms ease` | 기존 섹션·지도 제목 |

원본 MP 콘텐츠의 글꼴·제목 위계와 구성은 상속한다. 사이드바 폭·전개 애니메이션·iframe 높이·탭 칼럼 간격처럼 동작이나 배치에 필요한 값은 컴포넌트에 남긴다. 대한민국 Classic Routes의 기존 그룹 색상과 태극 SVG 색상은 의미가 다른 자산으로 유지한다.

적용 범위는 섹션, 지도, 통계, 사이드바, 루트 목록, 지역 디렉터리, 메인 진입 영역, Classic Routes 그룹, 번역 렌더러, 팝업 기본 스타일이다. 각 컴포넌트가 값을 직접 참조하므로 원본 페이지 전체에 전역 스타일을 강제로 덮어쓰지 않는다. 팝업은 같은 값에서 생성한 `--mpkr-*` 변수를 쓴다.

`NAV` / `UI.nav`는 승인된 다크 상단 바 팔레트다. 표면 `#202124`, 글자 `#fff`, 링크·포커스 `#91c3e8`, ON 스위치 `#5ba2d8`, OFF·테두리 `#5f6368`을 사용한다. 적용 결과 (로컬 참고: `design/review/navigation-applied.html`)는 별도 색상 덮어쓰기 없이 실제 소스를 렌더링한다.

## 대표 아이콘

- 원본 확인: [MP 공식 대표 아이콘](https://www.mountainproject.com/img/climb/favicons/favicon-180.png). 확인한 사이트의 favicon 링크를 사용했다.
- 로컬 원본: mp-icon-original-180.png (로컬 참고: `design/source/mp-icon-original-180.png`).
- 편집 결과: mp-korea-icon-master.png (로컬 참고: `design/mp-korea-icon-master.png`).
- 사용 위치: `public/icon/16.png`, `32.png`, `48.png`, `128.png`. `wxt.config.ts`의 `icons`와 `action.default_icon`에 연결했다.
- 편집 방식: 내장 imagegen으로 원본 심벌에 텍스트를 추가하고, 후속 요청대로 전체 폭의 큰 `KOREA`로 수정했다. 결과의 PNG 크기별 출력은 로컬 Chrome canvas로 수행했다. 원본과 픽셀 단위로 동일하다고 주장하지 않는다.
- 최종 편집 프롬프트 (로컬 참고: `design/icon-edit-prompt.txt`).

이제 확장 패키지에는 MP 아이콘을 바탕으로 만든 이미지가 포함된다. 기존 자산 검토 문서의 ‘런타임에 로고 파일 없음’은 이 변경 전의 관찰 기록이다. 현재 공개 배포 조건의 처리는 기존 출시 문서를 따른다.

## 현재 화면 기준

- 상단 컨트롤 바와 팝업은 다크 색상을 사용합니다. 대표 KOREA 아이콘과 원본 사용자 메뉴의 동작을 유지합니다.
- 원문 보기·재번역은 투명 배경의 밑줄 텍스트 컨트롤입니다. 불필요한 장식 SVG와 박스형 버튼은 사용하지 않습니다. 키보드 포커스와 진행 상태는 유지합니다.
- 섹션 접기·펼치기와 사이드바는 기존의 작은 화살표를 사용합니다. 추가 UI는 OFF 시 복원 가능한 구조로 구현합니다.
- 고정 폭 루트·등급 차트는 원본 노드를 유지하고 바깥 스크롤 영역으로 좁은 화면에 대응합니다. 차트 내용·높이·이벤트를 보존하며 OFF 시 추가 영역을 제거합니다.

## 유지보수

공통 색상·크기 변경은 `src/ui/design-tokens.ts`를 기준으로 합니다. 구성요소의 레이아웃, 키보드 조작과 OFF 복원은 관련 `test/ui/` 테스트 및 실제 브라우저에서 확인합니다. 빌드·검증 절차는 [개발 안내](development.md), 번역 안내 동작은 [번역 상태 안내](translation-status-notice.md)를 따릅니다.

과거 디자인 시안·승인 대화·환경별 작업 로그는 로컬 참고 자료입니다. 현재 규격과 검증 결과를 혼합하지 않으며, 시안의 모습만으로 실제 제품 구현이나 전 환경 검증 완료를 판단하지 않습니다.
