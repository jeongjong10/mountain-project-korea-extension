# 공통 디자인 기준과 단계별 컨펌

기준일: 2026-09-28. 이번 사용자 지시와 후속 수정 사항을 우선한다.

- 대표 아이콘은 MP 원본 클라이머 심벌에 `KOREA`를 추가한다. 후속 요청에 따라 글자가 하단 가로 폭 대부분을 차지하도록 확대했다.
- 현재 소스의 디자인 값을 추출해 공통화한다.
- **상단 바의 차콜·민트는 사용자가 원하는 디자인이 아니다.** 과거 문서의 ‘최종 선택’ 기록은 현재 선호의 근거로 사용하지 않는다.
- 밝은 회색·파란색 시안에서 후속 요청한 **다크 반전 시안이 승인됐다.** 어두운 중성 바탕·흰 글자·밝은 파란색 조작부를 실제 상단 바에 적용했다.
- 이후 팝업, 번역 상태 안내 등의 작업은 한 항목씩 결과를 보여주고 컨펌을 받은 뒤 이어간다.

원본 MP 콘텐츠의 글꼴·제목 위계와 구성은 상속한다. 사이드바 폭·전개 애니메이션·iframe 높이·탭 칼럼 간격처럼 동작이나 배치에 필요한 값은 컴포넌트에 남긴다. 대한민국 Classic Routes의 기존 그룹 색상과 태극 SVG 색상은 의미가 다른 자산으로 유지한다.

적용 범위는 섹션, 지도, 통계, 사이드바, 루트 목록, 지역 디렉터리, 메인 진입 영역, Classic Routes 그룹, 번역 렌더러, 팝업 기본 스타일이다. 각 컴포넌트가 값을 직접 참조하므로 원본 페이지 전체에 전역 스타일을 강제로 덮어쓰지 않는다. 팝업은 같은 값에서 생성한 `--mpkr-*` 변수를 쓴다.

`NAV` / `UI.nav`는 승인된 다크 상단 바 팔레트다. 표면 `#202124`, 글자 `#fff`, 링크·포커스 `#91c3e8`, ON 스위치 `#5ba2d8`, OFF·테두리 `#5f6368`을 사용한다. [적용 결과](../design/review/navigation-applied.html)는 별도 색상 덮어쓰기 없이 실제 소스를 렌더링한다.

## 대표 아이콘

- 원본 확인: [MP 공식 대표 아이콘](https://www.mountainproject.com/img/climb/favicons/favicon-180.png). 확인한 사이트의 favicon 링크를 사용했다.
- 로컬 원본: [mp-icon-original-180.png](../design/source/mp-icon-original-180.png).
- 편집 결과: [mp-korea-icon-master.png](../design/mp-korea-icon-master.png).
- 사용 위치: `public/icon/16.png`, `32.png`, `48.png`, `128.png`. `wxt.config.ts`의 `icons`와 `action.default_icon`에 연결했다.
- 편집 방식: 내장 imagegen으로 원본 심벌에 텍스트를 추가하고, 후속 요청대로 전체 폭의 큰 `KOREA`로 수정했다. 결과의 PNG 크기별 출력은 로컬 Chrome canvas로 수행했다. 원본과 픽셀 단위로 동일하다고 주장하지 않는다.
- [최종 편집 프롬프트](../design/icon-edit-prompt.txt).

이제 확장 패키지에는 MP 아이콘을 바탕으로 만든 이미지가 포함된다. 기존 자산 검토 문서의 ‘런타임에 로고 파일 없음’은 이 변경 전의 관찰 기록이다. 현재 공개 배포 조건의 처리는 기존 출시 문서를 따른다.

## 시안 검토와 다음 단계

1. 아이콘·본문 공통 값은 로컬 소스 및 빌드에 반영.
2. 상단 바 다크 버전은 사용자 컨펌 후 실제 소스 및 Chrome·Firefox 빌드에 적용 완료.
3. 다크 팝업은 사용자 컨펌 후 제품 소스에 적용 완료. KOREA 아이콘·설정 스위치·대한민국 링크·사용 안내·문의·manifest 버전을 표시한다. [실제 소스 렌더링](../design/review/popup-applied.html).
4. 번역 준비·미지원 안내는 승인 후 실제 상태에 연결했다. [적용 동작과 검증](translation-status-notice.md). 정상 번역에서는 표시하지 않는다.
5. 오류·상태 메시지는 승인 후 적용 완료. [실제 소스 적용 화면](../design/review/message-applied.html).
6. 사용자 수정 지시에 따라 추가 SVG 보조 아이콘을 제품에서 제거했다. 버튼·외부 링크는 텍스트만 표시하고, 접기·펼치기는 기존 CSS/문자 화살표만 남긴다. 예전 아이콘 시안은 현재 제품 디자인이 아니다.
7. 지역·루트 페이지 마감 1차 시안은 승인 후 적용했다. [실제 소스 검토 화면](../design/review/page-finish-applied.html). 추가 디자인 작업은 사용자 레이아웃 피드백에 따라 보류했다. 메인 진입 영역·지역 디렉터리 시안은 미적용 검토 이력이다. 통계·댓글 등 나머지 시각 마감은 후속 범위다.

검토 페이지는 실제 `NavigationControls` 소스를 사용하되 주변 헤더는 로컬 배치 검토용이다. 실제 MP 로그인 세션을 실행한 화면은 아니다. 확장 저장소·사용자 계정과 연결하지 않고 시안 내부 ON/OFF만 바꾼다. 공개용 독립 데모를 새로 게시한 것이 아니다.

로컬 재생성:

```bash
node design/build-review.mjs --approved
node design/build-popup-applied-review.mjs
node design/build-translation-applied-review.mjs
node design/build-message-applied-review.mjs
node design/build-icon-applied-review.mjs
node design/build-page-finish-review.mjs
node design/build-page-finish-applied-review.mjs
node design/build-directory-finish-review.mjs
```

`render-review.mjs`는 이 개발 환경의 임시 headless Chrome 경로를 사용한다. 다른 환경에서는 Chrome 경로를 맞춰야 한다. 검토 HTML의 맑은 고딕 참조는 로컬 글꼴이며 폰트 파일을 배포 자산에 포함하지 않는다.

- `UI.nav`를 공유하는 다크 팝업을 적용했다. native checkbox의 switch 역할과 키보드 조작, 외부 저장소 변경 구독을 유지한다.

## 오류·상태 메시지 승인 후 적용

- 상단 저장 실패는 스위치 아래의 전체 폭 안내로 표시한다. 오류 영역은 label 밖에 두어 안내를 눌러도 스위치가 바뀌지 않는다. 재시도·성공·외부 설정 반영 시 이전 오류를 숨긴다.
- 본문의 원문·재번역 버튼을 공통 스타일로 맞췄다. 재번역 버튼 이름은 유지하고 대기·동일·갱신·실패 결과를 옆의 live status로 표시한다.
- 원문 보호 등 상세 오류는 제목과 설명을 나눈 공통 메시지 스타일로 표시한다. 문단에 표시된 오류는 페이지 전체 안내에 반복하지 않는다. 준비 상태 조회 실패처럼 문단 오류가 없는 경우에는 페이지 안내를 유지한다.
- [검증 기록](../design/review/message-verification.json). 이 검증 당시 보조 아이콘은 시안 단계였으며, 아래 후속 승인 기록에서 적용했다.

## 보조 아이콘 적용 이력 — 이후 사용자 요청으로 되돌림

- 공통 소스: [이전 검토용 아이콘 원본](../design/archived-control-icons.ts). 직접 작성한 SVG 6종이며 16×16px, viewBox 24×24, 선 굵기 1.75, currentColor를 사용한다. 외부 아이콘 패키지를 추가하지 않았다.
- 원문·재번역·번역 준비/재시도, 지도·통계·팝업 외부 링크, 본문 섹션·지도·사이드바 펼침 표시에 연결했다. 등록 수 불러오기의 기존 화살표도 같은 다운로드 모양으로 정리했다.
- 한글 라벨을 유지하고 SVG에는 aria-hidden=true와 focusable=false를 지정했다. 상태 문구를 갱신할 때 SVG와 라벨을 분리해 아이콘이 사라지지 않게 한다.
- 접힘/펼침은 기존 aria-expanded와 키보드 동작을 유지하며, 펼침 SVG를 회전해 접힘 방향을 표시한다. 대표 KOREA 아이콘·태극 심벌은 그대로 사용한다.
- 관련 8파일 107개 테스트, production/test 타입 검사, Chrome·Firefox 빌드와 출력 번들 smoke 통과. [검증 기록](../design/review/icon-verification.json).

## 지역·루트 페이지 마감 1차 적용

- 승인한 시안의 간격·줄바꿈 규칙을 `AreaRoutePageFinish`로 연결했다. Area/Route 원본 글꼴·제목 크기를 상속하고 제목 줄높이 1.4, 관리 중인 섹션 제목의 위/아래 간격 24/12px, 본문 줄높이 1.65, 문단·버튼 위 간격 12px를 적용한다.
- 기존 루트 표의 칸과 링크를 유지한다. 행은 최소 44px, 셀은 세로 중앙 정렬하며, 긴 이름은 말줄임 대신 줄바꿈한다. 난이도는 줄바꿈을 막고 숫자 폭을 맞춘다. 링크 자체의 여분 최소 높이를 없애 이름과 난이도의 텍스트를 같은 높이에 배치한다.
- 적용 범위는 `#climb-area-page`, `#route-page`다. 기능 OFF와 파기 시 전용 style을 제거하며, 재활성화 시 중복 없이 추가한다. 사진·지도·통계 프레임·댓글 배치를 별도로 바꾸지 않는다.
- 관련 6파일 55개 회귀 테스트와 테스트 타입 검사를 통과했다. 마지막 CSS의 링크 높이·원본 여백 우선순위 조정 후에는 390·768·1000·1440px 실제 소스 검토 화면과 양쪽 브라우저 빌드를 다시 확인했다. [현재 보조 아이콘 제거 후 검증 기록](../design/review/minimal-controls-verification.json).
- 검토용 예시 DOM에서 가로 넘침, 짧은 루트명과 난이도의 텍스트 높이 차이가 0이었다. Enter/Space 접기·펼치기, 원문 전환, 스타일 해제·재적용을 확인했다. MP 실사이트 로그인 세션의 전수 검증이나 D8 전체 완료를 뜻하지 않는다.
- 다음 메인 진입 영역·지역 디렉터리는 검토 HTML에만 제안 스타일을 적용했다. 디렉터리 등록 수는 예시 값이며 제품 CSS·실제 조회 결과를 바꾸지 않았다.

## 현재 기준: 최소한의 텍스트 컨트롤

- 2026-09-29 사용자 요청으로 `.mpkr-original-toggle`·`.mpkr-retranslate`의 박스형 디자인도 되돌렸다. 기존 원문 보기 스타일의 투명 배경, 테두리·내부 여백 없음, 상속 글꼴/0.75rem, `#52635a` 밑줄 텍스트로 통일했다. 버튼 위 간격은 0.35rem로 복원하고 Area/Route의 추가 간격 덮어쓰기를 제거했다. 원문 전환·재번역·진행 상태 및 키보드 포커스는 유지한다.
- 사용자의 “꼭 필요한 곳을 제외하고 되돌려, 미니멀하게 텍스트만” 지시를 우선한다. 원문 보기·재번역·번역 준비·다시 시도·사용 안내·등록 수 조회와 지도·통계·팝업 외부 링크에서 추가 SVG를 제거했다. 번역 안내의 장식 원형 기호도 제거했다.
- 섹션 접기·펼치기는 원래 작은 CSS 화살표, 지도는 기존 문자 화살표, 사이드바는 기존 › 표시로 복원했다. 대표 MP KOREA 아이콘은 유지한다.
- 기존 SVG helper는 제품 소스에서 제거하고 과거 시안 재현용으로 design 폴더에만 보관했다. src에는 해당 helper의 참조가 없다.
- 저장된 South Korea 원본 HTML·CSS에 실제 application/navigation 코드를 적용해 1440·390px 폭과 OFF 시 복원을 확인했다. 외부 요청·사이트 스크립트는 차단하고 사진은 자리 표시자로 대체했으므로, 실사용 중인 모든 페이지의 레이아웃이 복구되었다고 판단하는 근거로 쓰지 않는다. [점검 결과](../design/review/minimal-controls-native-check.json).

## 2026-09-29 실제 확장 상태의 레이아웃 점검

- Codex 내장 브라우저는 Chrome 확장 적용 검증용으로 사용하지 않는다. Windows Computer Use는 현재 작업 폴더 URI 오류로 연결되지 않았다.
- 별도 Chromium 149 임시 프로필에 현재 Chrome MV3 빌드를 unpacked 확장으로 로드해 실제 공개 페이지를 점검했다. `chrome-extension://` 실행 컨텍스트와 확장 설정 스위치의 ON/OFF 동작을 확인한다. 스크립트 직접 주입 검사와 구분한다.
- 실제 대한민국 페이지의 고정 폭 Google Charts가 창 크기를 줄인 뒤에도 기존 457px 폭을 유지했다. 390px 화면에서 확장 적용 시 문서 가로 넘침이 147px 발생했다.
- 차트 노드를 교체하거나 축소하지 않고, `#route-chart`·`#rating-chart` 바깥에 높이가 자동인 스크롤 영역을 추가했다. 원본 차트 높이·내용·이벤트를 유지하며 방향키로 전체 내용을 볼 수 있다. OFF 시 wrapper를 제거해 원래 DOM을 복원한다.
- 적용 범위·검증 결과는 [2026-09-29 레이아웃 점검 기록](layout-verification-2026-09-29.md)을 따른다. 사용자 Chrome 프로필, Firefox 실브라우저, 로그인 상태 및 번역 품질의 전체 검증과 동일시하지 않는다.
