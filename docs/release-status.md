## 후속 로컬 변경 — 미출시

현재 소스에는 최초 OFF·스위치 강조 안내, ON 입력 시 자동 번역 준비와 별도 준비 버튼 미노출, 배포 도구가 추가되어 있습니다. 첫 실행은 설치 시점이 아닌 `enabled` 키 부재로 판단하므로 이전 설치도 설정을 저장하지 않았다면 대상입니다. 공개된 `0.1.0`의 기본 ON 동작과 구분합니다.

패키지 버전은 아직 `0.1.0`이며 새 버전 업로드·심사 제출·공개는 하지 않았습니다. 2026-10-01 후속 소스와 문서를 [e51e21e](https://github.com/jeongjong10/mountain-project-korea-extension/commit/e51e21e161171a1e4e403cdfbeb2277fc3482b43)로 `main`에 반영하고 푸시를 확인했습니다. Notion의 기준 문서·작업 카드도 동기화했습니다. 소스·테스트 타입 검사, Chrome·Firefox 빌드·번들 smoke, 배포 도구 6/6 검사를 통과했습니다. 전체 664개 중 661개 통과 후 실패한 3개 파일의 순차 재검사는 38/38 통과했으며 단일 전체 실행의 전수 통과는 아닙니다. 상세는 [검증 기록](documentation-sync.md)을 따릅니다. 최신 온보딩의 실제 Chrome 표시·언어팩 다운로드 완료는 아직 검증 증거가 없습니다.

## Desktop Whale 프로토타입

**2026-10-01 사용자 결정: 개발·추가 검증·배포 준비 중단.** 확인한 Whale `4.39.410.14`에서 고정 제목·메뉴 한국어 표시와 일부 탐색 기능은 동작했지만 본문 자동 번역은 제공하지 못했습니다. 현재 수준의 미출시 프로토타입으로 보존하고 정식 지원·제한 기능 배포·스토어 제출을 진행하지 않습니다. 이는 모든 Whale 버전의 영구 지원 불가 판정이 아닙니다.

W1·W2의 완료 이력은 유지하고, 미완료 W3·W4는 사용자 중단 사유를 기록해 작업 큐의 **보관됨** 상태로 전환합니다. 미검증 항목을 완료로 표시하지 않습니다. 기존 코드·빌드 명령·검증 증거는 보존하며 추가 서비스 진단·Papago 공존/연동·별도 번역 엔진·스토어 준비는 사용자의 명시적 재개 요청이 있을 때만 진행합니다. 아래는 중단 시점의 보존 기록입니다.

별도 `build:whale`·`zip:whale`와 브라우저별 배포 기록을 구현했습니다. 공통 소스를 재사용하는 MV3 툴바 확장이며, Chrome 공개본과 구분하는 **미출시 호환성 프로토타입**입니다. 패키지 버전은 `0.1.0` 그대로이며 웨일 스토어 제출·공개는 이번 작업 범위에 포함하지 않습니다.

빌드 성공이나 `prepared` 기록만으로 실제 Whale의 본문 번역 동등 지원·스토어 제출 준비 완료를 의미하지 않습니다. 설치 방법과 API 제한은 [웨일 설치 안내](whale-installation.md), 실행 환경·검사 결과·중단 시 미검증 항목은 [웨일 검증 기록](whale-validation-2026-10-01.md)에서 관리합니다. 앞 절의 Chrome·Firefox 검사 수치는 웨일 변경 전의 이력입니다.
