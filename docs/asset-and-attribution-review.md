## Architecture and Package Boundary

The extension changes pages visited on Mountain Project. Its map iframe loads an original Mountain Project `/map/...` URL; its stats iframe uses the original `/route/stats/...` link and validates the parent origin. This is same-site embedding within Mountain Project, not hosting copied pages or images on an external publisher's site. Map URL fallback uses the canonical `www` origin; same-site does not guarantee the same origin for every non-`www` navigation. See [map embedding](../src/ui/south-korea-map-embed.ts), [map URL resolution](../src/sites/mountain-project/dom/map-layout.ts), and [stats URL validation](../src/sites/mountain-project/dom/route-stats-layout.ts).

This supersedes the earlier 233,984-byte snapshot for this inventory only; a concurrently changing worktree/output is not a reproducible release manifest. No fixture, preview, development page dump, logo/photo/font file, or separate license notice was present in these five files. The popup HTML is the extension UI, not an MP page dump.
