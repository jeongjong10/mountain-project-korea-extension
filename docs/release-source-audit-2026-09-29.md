## 현재 소스로 확인한 사항

- 콘텐츠 진입점은 application/runtime, 사이트별 DOM 계약, Chrome 번역 provider, WebExtension 설정과 UI를 조합한다.
- 지역에 관계없이 유효한 Area·Route·Route Finder·Photo 구조의 본문을 처리한다. 검색·파트너 찾기·포럼·Help Hub 등도 구조에 따라 작성 콘텐츠를 번역한다. 기여 폼은 고정 UI를 처리하고 작성값·제출값은 보존한다.
- Help Hub Feature Request 제목·설명도 작성 콘텐츠 번역 대상이다. 작성자·투표 수 등 보호 대상과 구별된다.
- 본문 전처리는 DOM으로 확인한 이름, 기술 값 패턴과 구조 토큰을 보호한다. 일반 클라이밍 용어를 사전 한국어로 고정하던 경로는 제거되어 있다. 정책 버전은 `mpkr-policy-5`이다.
- 직접 요청은 지역 등록 수 조회의 `fetch` 경로에서 확인했다. 사용자 동작으로 시작하며 `credentials: omit`, 동시 요청 2개 제한과 중단 처리가 있다. 지도·통계 iframe 및 브라우저 모델 다운로드는 별도 통신이다.
- 확장 권한은 `storage`와 MP 두 HTTPS 호스트다. 지속 저장하는 확장 설정은 `storage.local.enabled`이며 기본값은 ON이다.
- OFF 시 application 기능, 번역 기록·캐시와 추가 iframe을 정리한다. 다시 켤 수 있는 내비게이션 shell은 남고 최종 runtime destroy 시 제거된다.
- 번역 결과는 텍스트 노드와 허용된 구조 복원으로 표시하며, 번역 문자열을 실행 코드로 평가하는 경로는 검색에서 확인되지 않았다.
- 통계 iframe의 쿠키 안내를 숨기는 selector가 현재 코드에 남아 있다. 지도·통계의 원본 고지와 동의 동작은 최종 실브라우저 검증에서 별도 확인할 항목이다.
