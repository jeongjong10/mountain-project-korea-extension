# 번역 준비·미지원 안내

2026-09-28 사용자 승인 후 적용했다. 이전 화면의 재현이 아니라, 내부에만 기록하던 번역 상태를 사용자에게 보여주는 새 안내다.

- 정상적으로 번역할 수 있는 페이지에는 안내를 띄우지 않는다. 번역 대상이 없는 페이지에서도 엔진 안내를 표시하지 않는다.
- `downloadable` 또는 사용자 동작 필요 오류가 기록되면 ‘번역 준비 시작’을 표시한다. 기존 페이지 클릭·키보드 동작에 따른 자동 재시도도 유지한다.
- 준비 버튼은 기존 `controller.retry()`를 호출한다. 작업 중에는 버튼을 비활성화하고 중복 호출을 막는다. 클릭에서 실제 provider 호출까지 기존 사용자 동작 경로를 유지한다.
- 준비·재시도 작업 동안 준비 중 문구를 표시한다. 엔진 다운로드 진행률은 알 수 없으므로 백분율을 만들지 않는다.
- 엔진 미지원은 사용 안내 링크와 함께 표시한다. 확장 ON과 본문 번역 지원 여부는 별개이며 고정 UI·탐색 등 지원 기능은 유지한다.
- 준비 상태 조회 또는 provider 번역 실패 시 원문을 유지하고 재시도를 안내한다. 보호 토큰·DOM 구조 검사로 번역을 보류한 `preserved` 상태는 문단 경고와 페이지 안내에서 제외한다. 원문과 재번역 버튼은 유지하며 재번역이 같은 이유로 거부되어도 오류 문구를 띄우지 않는다.
- 상태가 해소되거나 번역 대상이 제거되면 안내를 제거한다. OFF·종료 시 안내와 스타일도 제거하고, 늦게 완료된 작업으로 다시 삽입하지 않는다.

## 구현 경계

- `PageTranslationController`는 연결된 번역 대상의 실제 ledger 상태를 모아 `onNoticeChange`로 전달한다. 대상별 번역 결과·캐시·원문 복원 경로를 재사용한다.
- `TranslationNotice`는 문서당 하나의 안내를 렌더링한다. 번역 본문 근처에 삽입하고 접힌 `.mpkr-area-section-body` 바깥에 배치한다. 기존 MP 화면 전체를 교체하지 않는다.
- 컨트롤러·페이지 어댑터·고정 UI 로컬라이저는 `.mpkr-translation-notice`를 확장 소유 콘텐츠로 취급한다. 안내 자체를 번역 대상으로 다시 수집하지 않는다.
- 안내의 상태 문구는 `role=status`, `aria-live=polite`로 전달한다. 버튼은 native button을 사용하며 키보드 포커스를 표시한다.
- 후속 메시지 디자인 승인 후, 문단별 오류가 이미 표시된 경우 동일한 페이지 실패 안내를 생략한다. 재번역 결과는 버튼 옆 상태 문구로 표시한다. 준비·미지원 안내와 문단 오류가 없는 준비 상태 조회 실패 안내는 유지한다.

## 검증 자료

실제 소스 검토 화면 (로컬 참고: `design/review/translation-state-applied.html`)은 실제 컨트롤러·어댑터·렌더러·안내 UI를 모의 provider에 연결했다. 실제 Mountain Project 로그인 세션이나 Chrome 언어팩을 실행한 증거는 아니다.

[안내 통합 테스트](../test/ui/translation-notice.test.ts)는 정상 상태의 무표시, 미지원·원문 유지, 준비 버튼·중복 실행 방지, 실패 후 재시도, OFF 이후 늦은 완료, 대상 없음·대상 제거, 접힌 본문 밖 배치를 확인한다. 검증 기록 (로컬 참고: `design/review/translation-notice-verification.json`).

검증 결과: 최초 관련 3파일 33개와 최종 안내 테스트 8개가 통과했고 production/test 타입 검사, Chrome·Firefox 빌드와 출력 번들 smoke가 통과했다. 마지막 접힘 위치 수정 전에 시작한 전체 회귀 실행에서는 516개 통과·1개 실패를 기록했다. 실패한 위치 검사는 수정이 끝난 소스의 별도 실행에서 통과했다. 전체 회귀를 단일 전수 통과로 표기하지 않는다.

전체 실행 종료 후 최종 소스로 안내·application 수명주기 2파일을 함께 재실행해 16/16 통과했다. 이 검증은 최종 수정에서 생긴 위치 문제와 application 연결을 함께 확인한 결과다.
