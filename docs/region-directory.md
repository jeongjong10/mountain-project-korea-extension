# 암벽등반 가이드

현재 구현 명세. MP 원본 목록 스타일을 유지하며 아시아 / 유럽 / 아메리카 탭으로 전환한다. 첫 선택은 아시아다.

## 적용 범위와 구성

`#route-guide`가 있는 지원 페이지에 적용한다. 공개 페이지 18개 조사에서는 홈페이지와 `/route-guide`에서 확인했다. 다른 모든 URL·로그인 상태까지 전수 확인한 것은 아니다. 현재 문서를 마운트하며 이후 원본 디렉터리를 동적으로 교체하는 변형은 별도 대응이 필요하다.

| 탭 | 구성 |
| --- | --- |
| 아시아 | 대한민국 6개 권역을 첫 묶음으로 표시. 해외 8개국·34개 지역 추가. 튀르키예는 MP의 아시아 분류를 따름 |
| 유럽 | 7개국·31개 지역 |
| 아메리카 | 원본 `#route-guide` 전체. International 등 원본에 포함된 그룹도 보존 |

국가명은 국가 페이지로, 지역명은 해당 지역 페이지로 이동한다. 한국인 방문 빈도 순위는 아니다. 전체 조사 모집단 83개 국가·지역 항목 및 직속 하위 727개와 화면에 채택한 해외 15개국·65개 지역은 구분한다.

## 원본 스타일과 조작

- MP의 `mb-half`, `strong`, `ml-half`, `clearfix`, `number`, `float-xs-right`, `text-truncate`, `dashes`, `dashed-b` 마크업을 재사용한다. 색상·글꼴·들여쓰기·점선·우측 숫자를 원본 스타일에 맡긴다.
- 국가 묶음을 세로로 이어 4/2/1단으로 표시한다. 991px 이하에서 2단, 543px 이하에서 1단이다. 페이지 고유의 배경과 여백을 유지한다.
- 탭은 클릭 및 좌우 방향키·Home·End로 전환한다. ARIA로 선택 상태와 패널을 연결한다.
- `등록 수 불러오기` 버튼은 옅은 파란 배경·테두리·굵은 글씨·아래 화살표로 구분한다. 아메리카에서는 원본 숫자를 사용하므로 버튼을 숨긴다.

## 등록 수 조회

초기 로딩과 탭 전환에는 추가 네트워크 요청이 없다. 사용자가 버튼을 누르면 선택한 대륙에 필요한 MP 상위 지역 페이지 HTML을 조회한다. 국가 수치는 국가 전체, 지역 수치는 해당 지역의 하위 구역을 포함한 등록 루트·볼더 문제 수다. 표시한 후보 지역의 합계나 방문자 수가 아니다.

- 배포 데이터에는 링크·조회할 상위 페이지 URL만 저장한다. 조사 당시 고정 숫자는 배포하지 않는다.
- 상위 페이지별 요청을 중복 제거하며 동시에 2개까지 처리한다. 요청 제한 시간은 10초다. 현재 MP origin으로 요청하고 HTTP 캐시는 재검증하며 쿠키는 보내지 않는다.
- 받은 HTML은 실행하지 않고 등록 수를 파싱한다. `Total Climbs` 및 하위 지역 총수만 사용하며 종목별 부분 합계를 합산하지 않는다.
- 불러오는 중에는 중복 클릭을 막는다. 확인한 값은 표시하고 조회 시각을 툴팁에 남긴다. 실제 0은 0, 실패·미인식 값은 빈칸이다.
- 일부 실패 시 버튼으로 미조회 항목을 재시도한다. 성공한 숫자는 같은 화면에서 유지하고 다시 조회하지 않는다. 재시도 때문에 같은 상위 페이지를 다시 요청할 수 있다.
- 데이터는 해당 컴포넌트 생명주기 동안 메모리에만 유지한다. 새로고침 또는 OFF/ON 후에는 다시 버튼을 눌러야 한다. 지속적인 실시간 갱신이나 영구 캐시가 아니다.
- 로컬 `file:` 미리보기에서는 요청하지 않으며 버튼을 누르면 MP 사이트에서 사용할 수 있다는 안내를 표시한다.

## 원본 보존과 종료

원본 노드·부모·순서를 변경하지 않는다. 아시아·유럽에서는 원본의 hidden 상태만 변경하고 아메리카에서는 원본을 표시한다. OFF 시 원래 hidden 값을 복원하고 추가 UI·스타일을 제거한다. 진행 중인 요청을 취소하고 대기 요청·메모리 값을 정리한다. 제거된 화면에 늦게 도착한 응답은 반영하지 않는다.
